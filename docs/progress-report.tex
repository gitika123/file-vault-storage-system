\section{Architecture decisions}
\begin{itemize}[leftmargin=*]
  \item The backend is a modular Go monolith to preserve transactional consistency while keeping domain boundaries explicit.
  \item The shipped runtime uses REST for authentication, metadata, uploads, downloads, previews, search, sharing, and administration. A GraphQL SDL draft is retained as a preferred-contract extension because the hiring task accepts REST and prefers GraphQL.
  \item PostgreSQL stores logical file references separately from shared physical blobs.
  \item A user's quota is based on logical owned bytes. Per-user deduplicated usage counts each distinct referenced blob once.
  \item Public tokens, session tokens, and CSRF tokens are generated cryptographically; only hashes of session/public tokens are persisted.
\end{itemize}

\begin{itemize}[leftmargin=*]
  \item Project folders, issue ledger, implementation plan, ADRs, API contracts, and environment template.
  \item PostgreSQL schema for users, sessions, blobs, files, folders, tags, sharing, downloads, and audit events.
  \item Go configuration validation, PostgreSQL wiring, liveness/readiness endpoints, graceful shutdown, and structured logging.
  \item Argon2id password hashing, database-backed sessions, HttpOnly cookies, CSRF validation, owner/admin policy helpers, and live auth routes.
  \item Local blob staging with bounded streaming, SHA-256 calculation, safe generated-key validation, atomic rename, cleanup, and upload-limit checks.
  \item Content-signature MIME validation, multipart upload handling, database-backed blob reuse, and concurrent duplicate-upload verification.
  \item Transactional logical quotas, storage statistics, uploader-only deletion, reference-count-safe cleanup, and domain-level quota error mapping.
  \item Owner-scoped file listing with bounded cursor pagination, folder creation/listing, file rename/move, and validated owner-scoped tags.
  \item Combined parameterized search by filename, MIME, size, folder, and tags with bounded cursor pagination.
  \item Public and direct sharing mutations with cryptographically random public tokens, hashed persistence, expiration metadata, and revocation.
  \item Authorized private/direct/public downloads, allowlisted previews, download counters/events, and audit records.
  \item In-memory per-user API limiter enforcing the configured calls-per-second window for authenticated routes, with isolated unit coverage.
  \item React/Vite/TypeScript shell with signed-out authentication, responsive navigation, design tokens, identity, security status, and empty/error states.
  \item Vault dashboard with storage cards, owner-scoped search, file metadata list, upload entry point, and delete confirmation.
  \item Drag-and-drop multi-file upload with visible batch state, per-file rejection messaging, and refresh-on-completion.
  \item Local demo seed command for Alice, Bob, and Admin accounts; credentials are supplied at runtime and hashes are not committed.
  \item Compose API image includes the idempotent seed binary; local demo credentials remain environment-only and are never committed.
\end{itemize}
